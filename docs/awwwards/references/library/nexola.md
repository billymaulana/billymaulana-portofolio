## 1. Typography

- **display** — 200px / Inter Display 800 / 0em / lh 0.80
- **body** — 21px / 500 / 0em / lh 1.10
- **label** — 12px / 400–600 / 0em / lh 1.20
- **rasio display : body** — **9.5×**

## 2. Motion

scroll-scrub — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#0F0F0F` · ink `#F6F6F6` · aksen `#969696`
- pergantian ritme ground gelap ↔ terang antar section

## 5. Feels

Terkendali. Tracking 0 di semua tier membuatnya terasa netral dan institusional.
