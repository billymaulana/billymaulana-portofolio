## 1. Typography

- **display** — 427px / Inter 700 / −0.06em / lh 0.80
- **body** — 22px / 500 / −0.05em / lh 1.30
- **label** — 13px / 500 / −0.04em / lh 1.40
- **rasio display : body** — **19.4×**

## 2. Motion

scroll-scrub · text-reveal — terdeteksi: lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#0C0C0C` · ink `#FFFFFF` · aksen `#F9452D`
- ground hampir hitam, satu aksen merah-oranye

## 5. Feels

Menekan. Ukuran 427px pada viewport 1440 berarti tipografi adalah arsitektur, bukan teks.

## Yang diambil

Tracking negatif dipakai di SEMUA tier — display −0.06em, body −0.05em, label −0.04em. Bukan hanya display.

## Grid
