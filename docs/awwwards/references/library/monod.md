# Mōno™

![desktop](assets/monod-desktop.png)

![mobile](assets/monod-mobile.png)

## 1. Typography

- **display** — 176px / Inter 600 / −0.0455em / lh 0.85
- **body** — 19px / 600 / 0em / lh 1.10
- **label** — 13px / 700 / −0.02em / lh 1.50
- **rasio display : body** — **9.3×**

## 2. Motion

text-reveal · scroll-scrub — terdeteksi: lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#000000` · ink `#FFFFFF` · aksen `#F5F5F5`
- hitam-putih murni tanpa aksen warna sama sekali

## 5. Feels

Disiplin. Tidak ada satu pun elemen dekoratif; seluruh daya tarik berasal dari proporsi.

## Yang diambil

Single-family Inter, tiga weight (500/600/700), nol warna aksen — dan tetap tidak terasa kosong.

## Grid

Wordmark per-karakter 176px; body 19px; hanya tiga weight di seluruh situs
