## Apa yang Menarik
Editorial Swiss di light mode (#fcfcfc): wordmark 'OH Architecture' kiri-atas, nav WORKS/STUDIO/PROCESS/GALLERY tengah, pill 'GET IN TOUCH' + 'MENU' kanan (sticky). Hero foto full-bleed (Myrtle Pool House) dengan meta-row edge-anchored: 'FEATURED PROJECT' / 'MYRTLE POOL HOUSE' / '2024' / 'VIEW PROJECT'. Statement besar 'The OH Architecture style is defined by strong, solid forms...'. Section heading tipografis raksasa dengan counter — 'FEATURED WORKS (06)' — di atas image grid. Label kurung '(OUR STUDIO)' sebagai penanda section. Semua PP Neue Montreal.

## Teknik yang Diidentifikasi
GSAP + Lenis (smooth scroll) + Barba.js (page transition). Nav pill sticky (GET IN TOUCH + MENU toggle). PP Neue Montreal Variable untuk seluruh hierarki (wordmark/heading/body/label). Foto arsitektur full-bleed sebagai material utama. Grid 2-kolom untuk works. Palet minimal: near-white #fcfcfc + hitam.

## Timing & Feel
Diamati state statis. Terbukti dari stack: Lenis smooth scroll + Barba page transition. Scroll-reveal per section kemungkinan besar ada (GSAP) namun timing spesifik belum diukur.

## Kenapa Terasa Premium
1) Restraint ekstrem: satu typeface (PP Neue Montreal), dua warna (near-white + hitam), fotografi sebagai satu-satunya 'warna'. 2) Meta-row edge-anchored (FEATURED PROJECT / judul / tahun / VIEW) = editorial, bukan card generik. 3) Heading tipografis raksasa + counter ((06)) memberi otoritas & ritme. 4) Whitespace lega di kolom body = elegan, tenang. 5) Foto full-bleed berkualitas tinggi jadi konten, bukan dekorasi.
