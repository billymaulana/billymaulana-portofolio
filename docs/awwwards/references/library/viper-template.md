# Viper

![desktop](assets/viper-template-desktop.png)

![mobile](assets/viper-template-mobile.png)

## 1. Typography

- **display** — 260px / Inter Display 700 / −0.0346em / lh 0.77
- **body** — 18–20px / 600 / −0.005em / lh 1.20
- **label** — 12–13px / 500–700 / 0…−0.008em / lh 1.15
- **rasio display : body** — **13×**

## 2. Motion

scroll-scrub · cursor-driven — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#FF462E` · ink `#F9F9F9` · aksen `#EAEAEA`
- ground merah-oranye penuh sebagai blok, bukan aksen

## 5. Feels

Panas dan cepat. Leading 0.77 membuat dua baris nyaris bersentuhan.

## Yang diambil

Leading display 0.77 — lebih rapat dari 0.85 yang dipakai sebagai standar. Satu glyph (*) diberi warna aksen sebagai satu-satunya titik warna pada tipografi.

## Grid

Nama 260px dengan asterisk aksen berwarna; angka statistik 128px tracking −0.078em
