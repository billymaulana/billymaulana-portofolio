# Baselane Studio

![desktop](assets/baselane-desktop.png)

![mobile](assets/baselane-mobile.png)

## 1. Typography

- **display** — 369px / Switzer 400 / −0.02em / lh 0.90
- **body** — 20px / 400 / −0.01em / lh 1.50
- **rasio display : body** — **18.5×**

## 2. Motion

scroll-scrub · text-reveal — terdeteksi: lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#0A0A0A` · ink `#FAFAFA` · aksen `#737373`
- monokrom hangat; abu #D4D4D4 sebagai lapis kedua

## 5. Feels

Terukur. Grid 8 kolom terlihat jelas dari penempatan, bukan dari garis.

## Yang diambil

Grid 8 kolom / gap 14px, dan hanya DUA weight (400/500) di seluruh situs. Display 369px pada weight 400.

## Grid

Grid 8 kolom gap 14px; wordmark per-karakter 369px; body 20px di kolom sempit
