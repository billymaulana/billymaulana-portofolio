# Norvin

![desktop](assets/norvin-desktop.png)

![mobile](assets/norvin-mobile.png)

## 1. Typography

- **display** — 300px / Inter Display 600 / −0.06em / lh 0.93
- **body** — 20–24px / 400–600 / −0.01…0em / lh 1.17–1.20
- **label** — 12px / 500 / 0em / lh 1.33
- **rasio display : body** — **15×**

## 2. Motion

scroll-scrub · text-reveal — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#040404` · ink `#FFFFFF` · aksen `#9A9A9A`
- nyaris tanpa warna; pembeda hanya nilai

## 5. Feels

Hening dan mahal. Tracking −0.06em membuat kata menyatu jadi satu bentuk padat.

## Yang diambil

Tracking display −0.06em pada Inter 600 — jauh lebih rapat dari ambang lama −0.035em.
