# Porto

![desktop](assets/porto-template-desktop.png)

![mobile](assets/porto-template-mobile.png)

## 1. Typography

- **display** — 397px / Clash Display 600 / −0.0075em / lh 0.80 uppercase
- **body** — 24px / 600 / 0em / lh 1.00 uppercase
- **label** — 12px / 500 / +0.067em / lh 1.25 uppercase
- **rasio display : body** — **16.5×**

## 2. Motion

scroll-scrub · text-reveal — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#000000` · ink `#FFFFFF` · aksen `#161616`
- hitam berlapis: #000 / #0A0A0A / #161616 sebagai kedalaman

## 5. Feels

Tegas dan terstruktur. Uppercase di semua tier membuatnya terbaca sebagai poster.

## Yang diambil

Clash Display butuh tracking hampir netral (−0.0075em) karena sudah rapat secara bawaan — bukti bahwa tracking bergantung famili, bukan hanya ukuran.

## Grid

Masthead 397px uppercase; heading section 120px; garis vertikal grid terlihat sebagai elemen
