![mobile](assets/creativewebmanual-mobile.png)

## 1. Typography

- **display** — 256px / PP Neue Montreal 400 / −0.02em / lh 1.00
- **statement** — 136px / 500 / −0.02em / lh 1.00
- **body** — 24px / 500 / −0.02em / lh 1.10
- **rasio display : body** — **10.7×**

## 2. Motion

scroll-scrub · text-reveal · parallax — terdeteksi: gsap, lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#EAEAEA` · ink `#070707` · aksen `#262626`
- ground abu terang hangat, bukan putih layar

## 5. Feels

Seperti buku manual cetak. Tracking −0.02em seragam membuat seluruh halaman terasa satu sistem.

## Yang diambil

Tracking −0.02em identik di 256px, 136px, dan 24px. Konsistensi mengalahkan optimasi per tier.
