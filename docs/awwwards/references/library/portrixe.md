# Portrixe

![desktop](assets/portrixe-desktop.png)

![mobile](assets/portrixe-mobile.png)

## 1. Typography

- **display** — 162px / Satoshi 700 / −0.02em / lh 1.15
- **body** — 24px / 500 / −0.02em / lh 1.40
- **rasio display : body** — **6.75×**

## 2. Motion

text-reveal · scroll-scrub — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#FFFFFF` · ink `#131516` · aksen `rgba(0,0,0,0.3)`
- ground putih dengan ink hampir-hitam #131516, bukan #000

## 5. Feels

Lapang dan bersih. Leading display 1.15 memberi ruang napas yang tidak dimiliki referensi lain.

## Yang diambil

Satu-satunya di set ini dengan leading display longgar (1.15). Tracking −0.02em identik di display dan body — konsistensi sebagai sistem.

## Grid

Wordmark per-karakter 162px; statement 24px; single family di seluruh situs
