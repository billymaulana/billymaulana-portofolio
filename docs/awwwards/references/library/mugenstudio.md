# Mugen Design Studio

![desktop](assets/mugenstudio-desktop.png)

![mobile](assets/mugenstudio-mobile.png)

## 1. Typography

- **display** — 294–333px / Inter Display 700 / −0.04em / lh 0.80
- **body** — 20px / 600 / −0.03em / lh 1.50
- **label** — 12px / 600 / −0.02em / lh 1.12
- **rasio display : body** — **16.7×**

## 2. Motion

scroll-scrub · text-reveal — terdeteksi: lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#050505` · ink `#FFFFFF` · aksen `#B8B8B8`
- monokrom penuh; hierarki dibuat dari nilai abu, bukan hue

## 5. Feels

Berat dan tenang sekaligus. Dua kata bertumpuk dengan nilai berbeda membuat kedalaman tanpa efek apa pun.

## Yang diambil

Hierarki lewat NILAI, bukan ukuran: dua kata seukuran, satu putih satu abu #B8B8B8.

## Grid

Dua baris mega-type bertumpuk (MUGEN 294px / STUDIO 333px) dengan nilai abu berbeda; section case study 96px
