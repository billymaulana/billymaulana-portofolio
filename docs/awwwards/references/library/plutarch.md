# Plutarch Films

![desktop](assets/plutarch-desktop.png)

![mobile](assets/plutarch-mobile.png)

## 1. Typography

- **display** — 260px / Switzer 300 / −0.04em / lh 0.90 uppercase
- **statement** — 160px / 300 / −0.07em / lh 0.80 uppercase
- **body** — 14px / 500 / 0em / lh 1.30 uppercase
- **rasio display : body** — **18.6×**

## 2. Motion

scroll-scrub · parallax — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#000000` · ink `#FFFFFF` · aksen `#4A4A4A`
- abu #4A4A4A untuk teks besar yang mundur ke belakang

## 5. Feels

Sinematik dan dingin. Weight 300 pada ukuran raksasa membuat teks terasa seperti garis, bukan blok.

## Yang diambil

Teks display besar diberi warna abu gelap (#4A4A4A) agar mundur — hierarki lewat nilai, bukan ukuran saja.

## Grid

Grid 3–4 kolom gap 5–10px; angka indeks 260px; judul section 160px; meta 14px uppercase
