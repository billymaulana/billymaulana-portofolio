# Vitae®

![desktop](assets/vitaeresume-desktop.png)

![mobile](assets/vitaeresume-mobile.png)

## 1. Typography

- **display** — 264px / Switzer 300 / −0.10em / lh 0.70
- **masthead** — 240px / Switzer 500 / −0.05em / lh 0.70
- **body** — 14px / DM Mono 400 / −0.03em / lh 1.10 uppercase
- **rasio display : body** — **18.9×**

## 2. Motion

scroll-scrub · text-reveal — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#000000` · ink `#FFFFFF` · aksen `#0019FF`
- biru elektrik #0019FF — nyaris identik dengan identity #0047FF

## 5. Feels

Presisi ekstrem. Tracking −0.10em pada weight 300 membuat huruf nyaris bersentuhan tanpa terasa berat.

## Yang diambil

Weight 300 + tracking −0.10em + leading 0.70 pada 264px. Kombinasi paling ekstrem di seluruh set — dan tetap terbaca.

## Grid

Wordmark 240px; daftar kontak 264px sebagai navigasi; meta DM Mono 12–14px uppercase
