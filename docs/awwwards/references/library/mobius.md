# Möbius

![desktop](assets/mobius-desktop.png)

![mobile](assets/mobius-mobile.png)

## 1. Typography

- **display** — 326px / Inter Display 900 / −0.03em / lh 0.80
- **body** — 20px / 500 / 0em / lh 1.60
- **label** — 13px / Inter 600 / −0.005em / lh 1.70
- **rasio display : body** — **16.3×**

## 2. Motion

scroll-scrub · text-reveal — terdeteksi: lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#FFFFFF` · ink `#000000` · aksen `#FF0000`
- ground putih, aksen merah murni, foto oranye jenuh sebagai blok warna ketiga

## 5. Feels

Berani dan padat. Wordmark raksasa yang dipotong tepi bawah membuat halaman terasa lebih besar dari layar; foto yang menimpanya menciptakan kedalaman tanpa shadow.

## Yang diambil

Komposisi empat kuadran: teks kiri-atas, foto tengah, wordmark bawah menembus tepi, meta kanan-bawah. Bukan tumpukan rata kiri.

## Grid

Wordmark full-bleed terpotong tepi bawah; paragraf kiri-atas 6 baris; foto tumpang tindih di tengah; meta kanan-bawah
