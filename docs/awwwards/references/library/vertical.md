![mobile](assets/vertical-mobile.png)

## 1. Typography

- **display** — 409px / Inter 700 / −0.08em / lh 0.80
- **body** — 24px / 700 / −0.04em / lh 1.00 uppercase
- **label** — 12px / 600 / −0.03em / lh 1.10
- **rasio display : body** — **17×**

## 2. Motion

scroll-scrub · text-reveal — terdeteksi: lenis

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#050609` · ink `#FFFFFF` · aksen `#81FF28`
- hijau neon #81FF28 sebagai aksen tunggal di atas hampir-hitam

## 5. Feels

Tegang dan modern. Wordmark dipecah tiga blok membuat mata membaca vertikal, sesuai namanya.

## Yang diambil

Tracking −0.08em pada Inter 700 di 409px — paling rapat di antara referensi Inter. Grid 12 kolom sebagai fondasi.
