# Valtero X

![desktop](assets/valterox-desktop.png)

![mobile](assets/valterox-mobile.png)

## 1. Typography

- **display** — 513px / Humane 400 / +0.015em / lh 0.91
- **statement** — 259px / Coolvetica Condensed 400 / 0em / lh 0.90 uppercase
- **body** — 22px / Inter 400 / 0em / lh 1.12
- **rasio display : body** — **23×**

## 2. Motion

scroll-scrub · text-reveal — tidak ada library animasi terdeteksi (kemungkinan transisi bawaan Framer)

## 3. Visual effect

Tipografi ITU SENDIRI adalah efek visualnya — tidak ada shader, tidak ada partikel.
Level pada hierarki anti-slop: **1–2**, tapi lolos karena skala dan proporsi, bukan teknik.

## 4. Color

- ground `#000000` · ink `#FFFFFF` · aksen `#E6E3E3`
- monokrom; kontras dari skala, bukan warna

## 5. Feels

Ekstrem. Ukuran 513px pada viewport 1440 berarti satu kata mengisi sepertiga layar.

## Yang diambil

Pairing tiga famili dengan pembagian peran tegas: Humane (ultra-condensed) display, Coolvetica statement, Inter body/label.
