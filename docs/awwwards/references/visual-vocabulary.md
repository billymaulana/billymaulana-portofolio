# Visual Vocabulary

Bahasa visual dari situs award-winning. Bukan palette generator — ini cara berpikir tentang visual.

## Typography

### Extreme Contrast = Premium
Yang membedakan award-winning dari template: **jarak antara elemen terbesar dan terkecil**.

- Headline vs body = contrast di weight, size, spacing, line-height
- Condensed + sans-serif pairing (1820)
- Asymmetric sizing — tidak semua heading sama besar
- "Italic Rebellion" (BL/S): huruf pertama heading di-italicize — rhythmic gesture, planned imperfection

### Kerning Matters
"Fake spacing becomes painfully obvious when the headline is the hero." — Penev

Saat headline jadi focal point, setiap pixel spacing terlihat. Full kerning control bukan luxury — itu necessity.

## Color sebagai Narasi

### Jangan Pilih — Ceritakan
Warna punya makna. Jangan start dari palette generator.

| Project | Pendekatan | Alasan |
|---------|-----------|--------|
| Jason Bergh | #1e1e1e + cream (#FFEEC8) | "Dark editing suite at 3 AM" + aged film stock warmth |
| 1820 Productions | Pure monochrome | Isolasi dampak motion — warna = zero, motion = everything |
| Naked City Films | Monochromatic electric blue | Satu warna hapus noise; motion dan type carry design |
| Serhii W@W | Putih, hitam, orange (3 saja) | Light manipulation pada hitam untuk depth tanpa overwhelm |

### Rules yang Konsisten
- Hindari pure black (#000) — deep dark (#1e1e1e) punya lebih banyak depth
- Minimal palette: 2-3 warna maximum, surgical usage
- Warna sebagai atmosfer, bukan dekorasi

## Layout

### Content-Responsive, Bukan Template
Setiap project/section dapat **unique spatial logic** — mencegah visual repetition (Naked City Films).

### Brutalist Foundation
Structure visible dan intentional. Heavy blocks, deliberate spacing, scale create hierarchy TANPA decoration (Naked City Films).

### Asymmetric Typography + Grid
Serhii: asymmetric typography dengan harmonic spacing. Grid non-konvensional tapi masih punya internal logic. Swiss grid sebagai foundation, asymmetry sebagai expression.

## Atmospheric Detail

Detail yang terasa tapi tidak demanding attention:

| Teknik | Efek |
|--------|------|
| Animated noise + blending modes | Atmospheric color shifts, organic texture |
| Difference/Exclusion blend | Reveal Easter eggs, invert effects, X-ray aesthetic |
| Background blending | Mengarahkan attention secara selektif |
| Subtle gradient glow | Depth tanpa hard edges |
| Cultural references | Easter eggs (bouncing DVD logo, image-trail) reward exploration |

### Blending Mode Strategy (Serhii)
- `mix-blend-mode: difference` dan `exclusion` sebagai teknik utama
- Animated noise + blending = atmospheric color shifts
- Background blending untuk selective attention direction

## Planned Imperfection

Imperfection yang direncanakan memberi SOUL — membedakan dari template.

- **Jittery clip-path** (BL/S): bug yang dipertahankan 3 hari karena mirip camera shutter misfiring
- **Italic pertama** di heading: frame yang belum settle di projector
- **Analog noise**: referensi film grain, CRT, analog tech
- **CRT-inspired shader** (Naked City): dissolve images ke RGB channels

**Kunci**: imperfection harus PLANNED dan CONSISTENT dengan vibe project. Random glitch tanpa context = lazy.

## Konten sebagai Visual Language

"Those works themselves became the visual language." — 1820

- Zero stock photos
- Semua imagery dari project/konten actual
- Konten klien = material desain, bukan placeholder
