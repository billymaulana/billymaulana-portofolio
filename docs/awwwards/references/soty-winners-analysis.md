# SOTY Winners Analysis & Submission Strategy

Analisis pemenang Site of the Year (2019-2024), scoring system, dan strategi submission.

---

## SOTY Winners 2019-2024

### 2024 — Igloo Inc / Lusion v3
- **Jury Winner:** Igloo Inc (by abeto + Bureaux)
- **Also Jury:** Lusion v3 (Lusion studio)
- **Users' Choice:** Don't Board Me
- **Developer SOTY:** Igloo Inc (by abeto)
- **Tech:** WebGL, Three.js, immersive 3D scroll
- **Kenapa menang:** "Pure art" — immersive 3D, easy-to-navigate scroll, first-class micro-interactions, blazing fast performance, innovative creative vision. Lusion v3: cutting-edge WebGL experiments, sophisticated real-time animations.

### 2023 — Noomo Agency
- **Winner (Users' Choice):** Noomo Agency
- **Tech:** Nuxt 3, Three.js, GSAP, Node.js
- **Kenapa menang:** Extensive 3D animations, creative glass element integration, setiap hover punya unique purpose. Dynamic logo dari handwritten elements team. Blend AI tech + creativity. Serene colors + subtle 3D.

### 2022 — Persepolis Reimagined
- **Jury Winner:** Persepolis Reimagined (Getty Villa, by Media.Monks)
- **Developer SOTY:** Media.Monks
- **Tech:** WebGL 2.0 custom pipeline, instancing, LOD, frustum culling
- **Kenapa menang:** Virtual reconstruction ancient Persepolis. WebGL 2.0 instancing, geometry split → reassembled di WebGL. Amazing graphic quality + very impressive web performance.

### 2021 — Prometheus Fuels
- **Jury Winner:** Prometheus Fuels (by Active Theory)
- **Users' Choice:** Star Atlas (by Hello Monday)
- **Tech:** WebGL, 3D camera animations, illustrative + photographic elements on 3D meshes
- **Kenapa menang:** Stylized WebGL interactive story. Retrofuturistic aesthetics. Mix illustrative + photographic elements pada 3D meshes. Exceptional art direction dan storytelling.

### 2020 — Pioneer: Corn Revolutionized
- **Jury Winner:** Pioneer (by Resn + Bader Rutter)
- **Developer SOTY:** Kode Sports Club (Merci-Michel)
- **Users' Choice:** Bruno Simon Portfolio
- **Tech:** Resn's proprietary "Jelly" Web3D pipeline
- **Kenapa menang:** Unparalleled photorealism — depth of field, dynamic lighting, thousands of animated particles. All digital imagery from ground up. State-of-the-art 3D animation with fast load times.

### 2019 — Nomadic Tribe (Makemepulse)
- **Jury Winner:** Nomadic Tribe (73 votes)
- **Developer SOTY:** Bruno Simon Portfolio
- **Tech:** WebGL, immersive 3D
- **Kenapa menang:** Makemepulse internal project — "aesthetics into experiences with light-as-air tech with purpose." Studio punya 52 HM, 38 SOTD, 8 SOTM, 1 SOTY.

## Pattern Across All Winners

### Visual Patterns (Konsisten)
| Pattern | Frekuensi |
|---|---|
| Dark/rich backgrounds | Sangat umum |
| Bold typography | Universal |
| 3D/depth as design element | 100% sejak 2019 |
| High-contrast accents | Umum |
| Cinematic lighting | Tren naik |
| Glass/transparency effects | Naik |

### Technical Patterns (100%)
- **WebGL** present di 100% SOTY winners sejak 2019 — non-negotiable
- **Custom 3D pipelines** (Pioneer: Jelly, Persepolis: custom WebGL 2.0, Active Theory: Hydra)
- **GSAP** sebagai animation backbone
- **Scroll-driven experiences** — scroll adalah universal interaction driver
- **Custom shaders** — GLSL custom di semua winners

### UX Patterns
| Pattern | Detail |
|---|---|
| Scroll-as-narrative | Cerita unfold melalui scroll |
| Micro-interactions everywhere | Hover, scroll, cursor, click — semua punya response |
| Smooth scrolling | Universal (Lenis, custom, framework) |
| Creative preloader | Experience dimulai sebelum content loads |
| Intuitive navigation | Meskipun visual kompleks, navigasi tetap clear |
| Ambient animation | Continuous motion bahkan tanpa user interaction |
| Progressive reveal | Content reveals melalui scroll |

### Content Patterns
- Strong narrative arc — cerita koheren dari start to finish
- Minimal text, maximum impact — copy concise dan purposeful
- Visual-first storytelling — images/3D/video carry narrative
- Emotional resonance — create a feeling, bukan hanya informasi
- Clear value proposition — purpose immediately clear

## Scoring System Detail

### 4 Kriteria Evaluasi

| Kriteria | Bobot | Yang Dinilai |
|---|---|---|
| **Design** | 40% | Visual quality, typography, color harmony, layout, art direction |
| **Usability** | 30% | Navigation, UX flow, responsiveness, mobile, intuitive interaction |
| **Creativity** | 20% | Innovation, uniqueness, originality, pushing boundaries |
| **Content** | 10% | Copywriting, IA, storytelling, multimedia quality |

### Award Thresholds

| Award | Threshold | Mekanisme |
|---|---|---|
| Honorable Mention | >= 6.5 jury avg | Otomatis jika rata-rata jury mencapai |
| SOTD | Skor tertinggi (~8.0+) | Skor tertinggi dalam voting period |
| Developer Award | >= 7.0 dari dev jury | SOTD winners dikirim ke developer jury |
| SOTM | Top 8 SOTD/bulan | 8 SOTD tertinggi, jury review kedua + user votes |
| SOTY | Semua SOTM + favorites | Best of year, jury + community vote di Januari |

### Proses Jury
1. Minimum **18 jury members** evaluate per submission
2. **3 skor terjauh** dari rata-rata otomatis dieliminasi (outlier)
3. Voting **5 hari** per submission
4. Fast-track: skor tinggi jury + 10 PRO user votes = menang sebelum 5 hari
5. Max **3 bulan window** dari approval untuk menang SOTD

### Developer Award — Evaluasi Terpisah

| Area | Yang Dicek |
|---|---|
| Performance | Page speed, Lighthouse, WebPagetest |
| Accessibility | WCAG, screen reader, keyboard nav, reduced motion |
| SEO | Semantic HTML, meta tags, structured data |
| Code Quality | Cross-browser, interoperability, responsive |
| Inclusivity | Semua device, browser, users with disabilities |
| Mobile | Mobile optimization, touch interactions |

Tools evaluator: Lighthouse, PageSpeed Insights, WebPagetest, plus manual checks.

## Submission Strategy

### Biaya & Proses
- **$60** per submission (standard)
- **$170** untuk 5 submissions (hemat $130)
- Manual approval: sampai 1 minggu (bisa lebih saat weekend/backlog)
- Eligibility window: max 3 bulan setelah approval

### Checklist Submission
1. URL lengkap (https://)
2. Custom thumbnail (1600x1200px) — WAJIB stand out
3. Pilih showcase sections terbaik
4. Video walkthrough (HIGHLY recommended — dramatically increase visibility)
5. Deskripsi kuat — tekankan effort dan quality

### Tips Timing
- Submit **awal minggu** (Mon-Tue) — hindari weekend approval backlog
- Hindari holiday periods (Christmas, summer)
- Hindari bulan dengan conference launches besar (banyak agency submit bersamaan)
- Pastikan site 100% polished — hanya satu shot per submission

### Optimization untuk Jury
1. Video walkthrough berkualitas tinggi
2. Custom thumbnail yang menonjol di grid
3. Rally PRO user votes — share nomination link
4. Mobile harus sempurna — jury test di mobile
5. Performance — site lambat = jury kehilangan patience instantly
6. Build relationships di community — engage dengan submission lain

## SOTD → SOTM → SOTY Progression

### SOTD ke SOTM
- 8 SOTD tertinggi per bulan dinominasi
- Jury review kedua kali
- User votes carry extra weight
- Harus jadi single best site bulan itu

### SOTM ke SOTY
- Semua 12 SOTM + Awwwards favorites dari seluruh tahun
- Jury vote + community vote determine winners
- Users' Choice terpisah (most community votes)
- Voting period: Januari tahun berikutnya

### Lompatan Kualitas
SOTD → SOTM: **signifikan tapi incremental** — best of month vs best of day
SOTM → SOTY: **masif** — competing against 12 monthly champions. SOTY winners punya:
- Groundbreaking technical innovation
- Perfect art direction + storytelling
- Flawless execution across ALL criteria
- "Wow factor" yang persists bulan setelah pertama dilihat
- Something yang captures zeitgeist web design tahun itu

## Kenapa Sites TIDAK Menang

### Alasan Ditolak (Not Published)
- Pre-made templates (Squarespace themes, WordPress themes as-is)
- Template-looking designs (meski custom-built)
- Broken/incomplete (broken links, 404, unfinished sections)
- Not responsive (desktop-only)
- Copied concepts

### Alasan Skor Rendah
- Poor performance — slow load kills jury patience
- Bad mobile — carousels broken, touch-unfriendly
- Accessibility failures — no alt text, no keyboard nav, no reduced motion
- No storytelling — beautiful tapi tanpa narrative purpose
- No micro-interactions — static = dated
- Inconsistent — great hero tapi poor inner pages
- WebGL tanpa purpose — tech yang tidak serve content
- Navigation confusion — creative nav sacrifices usability
- No personality — generic corporate feel

### Technical Failures Spesifik
- Images loaded twice
- Files >5MB on initial load
- Missing image alt text
- Inaccessible pop-ups/forms
- Broken external links
- No focus management
- Placeholder-only form labels
