# Team Roles & Composition — Awwwards Studios

Siapa saja yang terlibat, apa yang mereka kerjakan, dan bagaimana mereka berkolaborasi.

---

## Core Roles

### Creative Director
- Menetapkan visi kreatif keseluruhan, menjaga konsistensi dari konsep sampai launch
- Representasi tim ke klien — pitching, approval final
- Fokus: copywriting, art direction, messaging, design, media distribution
- **Exo Ape:** Robbert Schefman — "a vision should never be handed off or diluted"
- **Immersive Garden:** Dilshan Arukatti — 10+ tahun memimpin semua aspek kreatif

### Art Director vs Design Director
- **Art Director:** Hands-on visual style, eksekusi detail, memimpin tim visual
- **Design Director:** Lebih umbrella — design system, konsistensi cross-project
- Di studio kecil pemenang Awwwards: CD dan AD sering **satu orang yang sama**

### Motion Designer / Animator
- Membuat interactive prototypes yang precisely convey bagaimana motion seharusnya
- Dokumentasi: breaking down gerakan kompleks agar developer memahami
- Spec detail: duration, easing curve, delay, stagger values
- Handoff: AE compositions diekspor sebagai Lottie JSON, atau spec manual
- Prinsip: "embrace collaboration, be open to changes" — mau adapt berdasarkan technical constraints

### Creative Developer / Creative Technologist
**Definisi (Bruno Simon):** "A creative developer is oriented toward the visual and experiential side of the web — building things that look like video games, that surprise and delight."

**Skills yang dibutuhkan:**
```
SKILL TREE CREATIVE DEVELOPER:

[PROGRAMMING]
├── JavaScript/TypeScript (advanced)
├── WebGL / WebGPU (raw API level)
├── GLSL / WGSL shader programming
├── Three.js / R3F / OGL
├── GSAP ecosystem (ScrollTrigger, SplitText, Flip)
└── Canvas 2D API

[MATHEMATICS]
├── Linear algebra (matrices, vectors, quaternions)
├── 3D geometry & spatial relationships
├── Noise functions (Perlin, Simplex, fBm)
├── Physics simulation basics
└── Color space math

[DESIGN]
├── Motion design principles
├── Typography (fluid scales, hierarchy)
├── Color theory
├── Layout & composition
└── Figma proficiency

[SOFT SKILLS]
├── Collaboration dengan designers & animators
├── Communication tentang technical constraints
├── Creative problem-solving
└── Performance optimization mindset

[BONUS]
├── VFX knowledge
├── Game design concepts
├── Fine arts appreciation
├── Sound design basics
└── Houdini / Blender untuk prototyping
```

**Salary:** $109K-$186K/year (US). Freelance: $50-90/hour (North America)

### Front-end Developer vs Creative Developer Spectrum

| Aspek | Front-end Dev | Creative Dev |
|---|---|---|
| Fokus | Functionality, data binding | Visual experience, delight |
| Tools | React/Vue, REST APIs, state mgmt | WebGL, GLSL, GSAP, Canvas |
| Design | Implements Figma pixel-perfect | Co-creates dengan designer |
| Output | Web apps, dashboards, SaaS | Immersive experiences, portfolios |
| Motion | Basic CSS transitions | Deep easing, physics, particles |
| Math | Basic algorithms | Linear algebra, noise, fluid dynamics |
| Art sense | Nice to have | **Essential** |

### UX Designer / Interaction Designer
- Merancang user journey intuitif meskipun ada efek visual kompleks
- Memastikan accessibility (reduced motion, keyboard nav)
- Wireframes dan prototypes untuk interactive flows
- Balance "wow factor" vs usability (Awwwards: Usability = 30%)

### 3D Artist / WebGL Developer
- 3D models, textures, animations berkualitas tinggi
- Prototype di Blender/Houdini/Cinema4D, optimize untuk real-time web
- Lusion: prototype di Houdini, reproduce di WebGL untuk production
- Tools: Blender, Houdini, Cinema4D, Substance Painter → Three.js/OGL untuk web

### Digital Producer (bukan "Project Manager")
- Lebih terlibat dalam proses kreatif — bukan hanya timeline management
- Menyediakan "all necessary conditions to take a project as far as possible creatively"
- Tracking production costs, managing timeline, recruiting teams
- **Immersive Garden:** Daisy Potfer (Producer & Partner) — salah satu leader utama
- Punya functional knowledge tentang creative process

### Sound Designer
- Masih niche tapi semakin penting
- Web Audio API untuk spatial sounds dan immersive soundscapes
- "UI sound design is a real craft, deserves more than an afterthought"
- Biasanya outsourced/freelance — jarang in-house di studio kecil

### Kenapa Solo Developer Bisa Menang?
1. Mereka designer DAN developer — hybrid skill set langka
2. Portfolio sebagai proving ground — site = demo kemampuan
3. No libraries / custom everything → output unik
4. Community teaching membangun nama dan network
5. Selective collaboration untuk project klien

## Collaboration Patterns

### Exo Ape: Compact Core + Extended Network
- 3 founders masing-masing punya domain (Creative, Digital/Motion, Technical)
- Visi tidak pernah di-handoff
- Scaling: freelance network saat project membutuhkan

### Lusion: Mood Board → Prototype → Production
1. Concept & Visualization (mood board)
2. Visual References (inspirational images/video)
3. Prototyping (Houdini, kadang sacrifice effects)
4. Production (reproduce di WebGL, optimize)

### Makemepulse: Trust, Transparency, Teamwork
- Developer di bawah Technical Director
- Kontribusi dari pre-production sampai delivery
- Internal projects untuk strengthen team cohesion

### Insight Utama
Studio pemenang TIDAK menggunakan traditional handoff (designer bikin, developer implement). Mereka pakai **collaborative creation** — designer dan developer duduk bersama dari awal.

---

## The Developer-Designer Hybrid

Kenapa hybrid model works untuk Awwwards:
1. **Zero translation loss** — tidak ada miskomunikasi
2. **Faster iteration** — satu orang adjust design + code simultaneously
3. **Unified vision** — aesthetic + technical decisions oleh satu pikiran
4. **Unique output** — tidak ada handoff = selalu distinct
