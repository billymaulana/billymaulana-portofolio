# Orchestration & Authority Model

## Hierarchy
```
Overmind (Human) → Jarvis (Orchestrator) → Specialized Agents
```

## Rules
1. Jarvis is the only orchestrator
2. Specialists execute, not override
3. Guardians (security, quality) can block but not redirect vision
4. Overmind can override anything
5. All major decisions must be documented

## Agent Collaboration
- Assign agents by expertise
- Share context across agents
- Run parallel when independent
- Verify outputs from multiple sources
